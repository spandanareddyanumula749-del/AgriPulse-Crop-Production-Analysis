\# 🌾 Crop Analysis \& Agricultural Production Dashboard



\## 📌 Project Overview



This project analyzes agricultural crop production data to identify patterns and trends across different states, crops, seasons, and years.



The project follows a complete data analytics workflow involving \*\*data cleaning, transformation, SQL analysis, and interactive dashboard development\*\*.



The final analysis is presented through an interactive \*\*Power BI dashboard named "AgriPulse"\*\*, which provides insights into crop production, cultivated area, yield, state-wise performance, and crop-wise trends.



\---



\## 🎯 Objectives



\- Analyze agricultural production across different states and crops.

\- Identify crops with the highest overall production.

\- Compare agricultural production across states.

\- Analyze production trends across different seasons and years.

\- Study the relationship between crop area, production, and yield.

\- Build an interactive Power BI dashboard for data-driven insights.

\- Demonstrate an end-to-end data analytics workflow using multiple tools.



\---



\## 📊 Dataset



The dataset contains agricultural production records covering:



\- \*\*246,091 cleaned records\*\*

\- \*\*33 states\*\*

\- \*\*124 crops\*\*

\- \*\*1997–2015\*\*

\- Multiple agricultural seasons including:

&#x20; - Kharif

&#x20; - Rabi

&#x20; - Summer

&#x20; - Winter

&#x20; - Autumn

&#x20; - Whole Year



\### Key Columns



| Column | Description |

|---|---|

| State | State where the crop was cultivated |

| District | District where the crop was cultivated |

| Crop Year | Year of cultivation |

| Season | Agricultural season |

| Crop | Name of the crop |

| Area | Cultivated area |

| Production | Crop production |

| Yield | Production efficiency/yield value |

\## 🐍 1. Data Cleaning with Python



Python and Pandas were used to prepare the raw dataset for analysis.



\### Major preprocessing steps



\- Checked the dataset structure and data types.

\- Identified missing values.

\- Removed duplicate records.

\- Checked zero and invalid values.

\- Converted numerical columns into appropriate formats.

\- Calculated and prepared yield-related values.

\- Created a cleaned dataset for further analysis.



The cleaned dataset contains \*\*246,091 records\*\*.



\---



\## 🗄️ 2. MySQL Analysis



The cleaned crop production data was imported into MySQL for structured data storage and SQL analysis.



The database was used to perform queries such as:



\- Total crop production.

\- State-wise production.

\- Crop-wise production.

\- Season-wise production.

\- Year-wise production.

\- Identification of top-performing crops and states.

\- Aggregation of production and yield metrics.



\---



\## 📈 3. Power BI Dashboard



The final analysis was visualized using Power BI through the \*\*AgriPulse\*\* dashboard.



\### Dashboard Highlights



\- Total agricultural production

\- Crop-wise production

\- State-wise production

\- Production by season

\- Crop production trends

\- Production vs cultivated area

\- Yield analysis

\- Top 10 crops

\- Interactive slicers and filters

\- Dynamic DAX-based measures



\### Key Insights



\- \*\*Coconut\*\* records the highest total production among the crops in the dataset.

\- \*\*Kerala\*\* records the highest total production among the states.

\- The dataset contains \*\*33 states and 124 crops\*\*.

\- Production records span from \*\*1997 to 2015\*\*.

\- Production varies significantly across crops, states, seasons, and years.
